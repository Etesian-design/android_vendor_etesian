# Etesian icon

`etesian-deep.svg` and `etesian-pearl.svg` are copied from the Etesian-design/design repo (`brand/`), which is
their source. Deep is for dark surfaces, pearl for light ones.

`render.py` turns them into `launcher/app/src/main/res/drawable-nodpi/etesian_icon_{deep,pearl}.png`; run it again
after the SVGs change.
